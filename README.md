
# Smart Home Dashboard

## Description

A smart home dashboard designed to monitor and control different home systems through a simple and user-friendly interface.

## Features

* 🏠 Smart home dashboard interface
* 💡 Lighting control
* 🌡️ Temperature monitoring
* 📹 Security and camera section
* 📺 Device and room management
* 📊 Energy consumption monitoring
* 🎨 Clean and responsive design

## Technologies Used

* HTML5
* CSS3
* Font Awesome

## Project Purpose

This project was created as a practical project to improve my skills in web development, user interface design, and smart home technology.
